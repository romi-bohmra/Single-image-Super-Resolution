Put the trained checkpoints (state_dicts saved from Colab) in this folder:

    srcnn_y_model.pth             SRCNN-Y
    vdsr_y_model_300_fixed.pth    VDSR-Y
    srgan_y_G.pth                 SRGAN-Y generator

Any file that is missing is simply skipped (its button is greyed out in the UI),
so the tool also works with just one or two models.
